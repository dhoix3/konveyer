# FIXES 5 — стабильность рендера, контракт света, GUI-упрощение

Дата: 2026-11-25 · ветка: `arena/19d15353-konveyer` (от `main` @ 3bed235)

## 1. Исправленные проблемы

### P1 — «TypeError: Cannot read properties of undefined (reading 'pulse')» (исходная задача)

Ошибка возникала в `SceneRenderer` на первой сцене `s01` проекта `gravity-film`:
проект, созданный через universal-мастер (`make`, режим unverified-draft), содержал
сцены без обязательного поля `scene.light` (`SceneSpec.light` — обязательный
`LightDef`, но генератор его не записывал). Первый же доступ
`scene.light.pulse.period` в `src/v2/SceneRenderer.tsx:222` падал в Chrome.

Исправлено как **контракт данных**, а не `?.`-заглушкой:

1. **Генератор** (`tools/universal.mjs`): outline-сцены теперь несут полный
   `light` (`L('none',960,300,'#8fb0ff','#8fb0ff',0.35,{grade:'cold'})`).
2. **Граница плана** (`tools/timeline.mjs`, единственный продюсер `plan.json`):
   каждая сцена проходит `normalizeSceneLight()` (новая экспортируемая функция в
   `tools/story.mjs`). Валидные авторские поля сохраняются как есть; отсутствующие
   или невалидные достраиваются детерминированным пресетом `env:time`
   (`lightFor`). Старые проекты (включая повреждённые без `light`) снова
   рендерятся — совместимость сохранена, content-сцены не изменяются.
3. **QA** (`tools/qa.mjs`): неполный `light` — ошибка план-QA
   («scene light missing», «scene light.x …», «scene light.pulse must be
   {color, period>0}»), перехватывается до Chrome.
4. **Регрессионный тест** `tests/fixes5.mjs`: воспроизводит `gravity-film`
   end-to-end (в т.ч. проект с вручную удалённым `light`), прогоняет **реальный
   `SceneRenderer`** по всем кадрам сцены `s01` (headless SSR через
   `react-dom/server`, `tests/ssr-*.mjs`; только contract/render-path проверка,
   не пиксельная) и по одной сцене каждого пути генерации
   (что-если/story/production/series/documentary/universal) + QA-негативы.

Добавлен пресет света `void:night` в `LIGHTS` (`tools/story.mjs`) — пустая сцена
больше не откатывается к «уличному солнцу».

### P2 — QA media падала на минимальных сборках FFmpeg

Remotion-комплектный Linux-ffmpeg собирает/монтирует видео, но не содержит
**видеофильтров** (`blackdetect`/`freezedetect`) и `-f null` энкодера: реальный
прогон `all` давал 5 ложных ошибок «FFmpeg visual QA failed … Encoder not found».
Теперь `qaMedia()` зондирует возможности сборки (`videoFilterSupport()`): при
отсутствии фильтров проверка помечается в `qa_report.json` как
`notChecked: ["blackdetect/freezedetect … NOT machine-checked"]` и дублируется в
лог (`NOT CHECKED: …`). Разрешение/фейл/фейк не подмешиваются: структурные
проверки (fps/разрешение/длительность/кодек/LUFS) выполняются как прежде.

### P3 — GUI был недоступен из reverse-proxy превью

`checkBoundary` жёстко требовал Host == bind-хост и точный порт. Добавлен явный
allowlist `KOVEYER_PROXY_HOSTS` (glob: `*.e2b.app` → поддомены на 1+ меток;
голый домен, чужие домены, суффикс-спуфинг и неверный порт по-прежнему 403;
loopback-хосты без переменной работают ровно как раньше — покрыто тестами в
`tests/reliability.mjs`). Побочно исправлена логика `hosts.has(hostname)`,
которая блокировала любые нелокальные хосты до проверки allowlist.

## 2. Изменения интерфейса

- **Раздел «Дополнительно»**: редкие настройки убраны из основного потока
  свёрнутые блоки — жанр/продолжение (`Дополнительные параметры замысла`),
  эпизоды/повествование/модель диктора (`Дополнительные параметры производства`),
  шаблон/id/перезапись (`Дополнительные параметры запуска`). Кнопки «Проверить
  компоненты» и папки — под «Сервис».
- **Озвучка поднята** в основной поток создания (рядом с персонажами/языком).
- **Понятный статус производства**: панель этапов показывает человеческую
  строку «что происходит / что нажать дальше» (`#nextStepHint`): идёт этап →
  ошибка этапа с подсказкой про «Повторить» и журнал → следующий шаг по имени
  («таймлайн — расчёт длительности сцен», «рендер сцен (нужен локальный
  Chrome)», …) → «все этапы завершены, смотрите FINAL.mp4; автопроверка не
  заменяет ваш просмотр».
- Технические значения (id шаблонов, enum) в интерфейсе не добавлялись;
  локализация RU/EN сохранена, API не изменён (только перестановка разметки).

## 3. Новые возможности (без расширения объёма)

- `normalizeSceneLight` + QA-контракт света (см. P1) — защита от всего класса
  «генератор забыл поле».
- Capability-probe QA и поле `notChecked` в отчёте — честная граница «что
  машина не проверяла» вместо ложных ошибок.
- `KOVEYER_PROXY_HOSTS` — безопасный доступ к локальному GUI через прокси-превью
  (тот же bearer/cookie, тот же Origin-check).
