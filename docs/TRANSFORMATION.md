# Koveyer Dhoix'a — план трансформации

## Аудит исходной системы

CLI render.mjs и HTTP GUI используют один project.json. script/story создают
правиловый сценарий; voice.mjs/Piper пишет манифест; timeline разрешает якоря;
Remotion рендерит SVG-сцены; sound/FFmpeg собирают звук и экспорт. Уже существуют
lock, fingerprints, Chrome discovery и регрессии. Их сохраняем.

Проблемы концепции: единственный формат «что если», нет производственного брифа,
контейнера сезона и реестра источников. Выбранный cast мог не участвовать в сценах.
Текущая графика — стилизованные SVG-персонажи, не фотореалистичная реконструкция.

## Этапы и критерии

1. Аудит и этот план; проверить чистоту ветки и прежние команды.
2. Новый бренд, сгруппированная форма, production metadata; старый JSON читается.
3. Отдельный provider правиловых сценариев с контрактом для будущего LLM,
   явными ролями и обязательным участием cast; измеряемый бюджет речи.
4. Источники и утверждения отдельно от сцен. Документальный текст не получает
   выдуманных дат/цитат; без материалов — явно помеченная заявка, не факт-фильм.
5. Season container + самостоятельные episode projects, context snapshots,
   регенерация отдельного эпизода без перезаписи остальных.
6. Визуальные профили поверх существующих env/camera, сохранение Piper/FFmpeg.
7. Автотесты legacy/new, doctor и попытка настоящего рендера. Непроверенные
   возможности и системные блокеры фиксируются отдельно.

Новые возможности добавляются аддитивно. Никаких моделей в Git, удалений проектов,
force push, смены ветки или публикации без отдельного решения.

## Реализация

Этапы 2–5: добавлены production.mjs / series.mjs, GUI-бриф, учебный документальный
режим, реестр источников, независимые эпизоды, snapshot событий, история cast,
продолжение и выборочная регенерация. Старые regression/runtime/topics проходят;
добавлены 30 новых production cases и тесты season/continuation/evidence.

Этап 6: существующий рендер не заменён, добавлены жанровые профили и участие cast.
Реальный 25-секундный draft выявил и позволил исправить финальное имя черновика
и loudnorm MP4 (нужно исключать видеопоток через -vn). Сам pipeline завершился,
файл полностью декодируется. Финальные эпизодные экспорты проверяются отдельно.

Нереализованное: интеллектуальная причинная драматургия для произвольной темы,
фактчекинг/поиск источников, фотореалистичные визуальные реконструкции,
автоматическое распространение ручных изменений событий на последующие серии,
автоматическое восстановление частично записанного сезона при дисковом сбое.
